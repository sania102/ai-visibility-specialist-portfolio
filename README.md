# AI Visibility Technical Specialist — Portfolio Demo

A polished multi-page static website demonstrating technical SEO and AI visibility foundations.

## Pages and files
- `index.html`: overview and relevant experience
- `approach.html`: semantic content, metadata, crawlability and AI discovery notes
- `schema.html`: JSON-LD implementation notes and validation instructions
- `about.html`: professional background
- `styles.css`: responsive visual design
- `robots.txt`, `sitemap.xml`, `llms.txt`: crawler and AI-oriented discovery resources

## Deploy with GitHub Pages
1. Create a **public** repository named `ai-visibility-specialist-portfolio` under GitHub account `sania102`.
2. Upload all files in this folder to the repository root (not the enclosing folder).
3. Open Settings → Pages.
4. Select Deploy from a branch, branch `main`, folder `/ (root)`, then Save.
5. Wait for deployment to complete.
6. Test the homepage and `/schema.html`.

Expected URL: https://sania102.github.io/ai-visibility-specialist-portfolio/

If using a different username or repository name, update absolute canonical URLs, Open Graph URLs, JSON-LD IDs, robots.txt, sitemap.xml and llms.txt before deployment.

## Validate
Use https://validator.schema.org/ with the deployed `/schema.html` URL. Confirm Person, WebSite, WebPage and FAQPage entities are detected and capture the actual result.

Google's Rich Results Test is not a general-purpose validator for every Schema.org type. Valid markup does not guarantee a Google rich result.
