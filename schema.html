This page documents the JSON-LD implementation in the portfolio. The structured data describes the author, website and individual page with linked entity identifiers.

Entity graph

What the markup describes

The JSON-LD is embedded in the HTML head and uses a shared @context and @graph.

SCHEMA TYPE 01

Person

Describes Sania Shamsi as the portfolio author and links to the public portfolio and GitHub profile.

SCHEMA TYPE 02

WebSite

Describes the overall portfolio website and identifies the Person entity as its publisher.

SCHEMA TYPE 03

WebPage

Describes this individual page and connects it to the website and author entities.

Implementation sample

Connected identifiers

"@graph": [
  {
    "@type": "Person",
    "@id": "…/#sania",
    "name": "Sania Shamsi"
  },
  {
    "@type": "WebSite",
    "@id": "…/#website",
    "publisher": {"@id": "…/#sania"}
  },
  {
    "@type": "WebPage",
    "@id": "…/schema.html#webpage",
    "isPartOf": {"@id": "…/#website"},
    "about": {"@id": "…/#sania"}
  }
]

The production HTML contains the complete absolute URLs. The shortened identifiers above are illustrative only.

Validation

Verify the deployed page

  1. Deploy this site publicly and open the live schema.html page.
  2. Paste that exact URL into the Schema.org Markup Validator.
  3. Confirm the detected Person, WebSite, WebPage and FAQPage entities.
  4. Capture a screenshot of the actual validator result for the screening submission.

Google's Rich Results Test checks eligibility for Google rich-result features; it is not a general-purpose validator for every Schema.org type.

FAQ

Common questions

What structured data is implemented on this site?

The site implements Schema.org Person, WebSite and WebPage entities using JSON-LD.

Does valid structured data guarantee a Google rich result?

No. Valid structured data does not guarantee a rich result. Google determines eligibility and display at its discretion.

How can the structured data be checked?

Use the Schema.org Markup Validator to inspect detected Schema.org entities.
